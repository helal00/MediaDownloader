People who may download

Users who do not manage the server cannot open the dashboard. Allow them here, each limited to their own folders; they use the downloader at (sign in with their Jellyfin account; bookmark it or add it to the phone's home screen). Administrators can use that page too, with every library folder.
Each folder must be a library folder or inside one (for example C:\MOVIES\movies\Babui); it is created on the first download. Give the user access to that library too (Dashboard > Users > the user > Library access), so they can play what they download.
Everyone sees it in the menu (☰) of the Jellyfin web page and apps; people you did not allow are told so when they open it. Nothing in Jellyfin's own files changes, so the link stays after Jellyfin updates. After changing it, reload the Jellyfin page.
